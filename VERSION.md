# История версий

## Версия 1.0.0 (22 ноября 2025)

### 🎉 Первый релиз

Полнофункциональная система управления полисами для страхового брокера.

### ✨ Основные возможности

#### Управление данными
- Учет клиентов (лизингополучателей)
- Справочники страховых компаний
- Управление филиалами
- Виды страхования
- Ставки комиссий

#### Полисы
- Создание и редактирование полисов
- Многолетние договоры
- График платежей с дроблением
- Автоматический расчет комиссий
- Статусы активности (полис, ДФА)
- Инфо-метки для классификации

#### Веб-интерфейс
- Дашборд с аналитикой
- Журнал полисов с фильтрами
- Детальные карточки полисов
- График платежей
- Справочник клиентов
- Responsive дизайн (Bootstrap 5)

#### Отчеты
- Экспорт полисов в Excel
- Экспорт очередных взносов в Excel (с фильтрацией по диапазону дат)
- Четверговый отчет
- Фильтрация перед экспортом

#### Автоматизация
- Автоматический расчет комиссии в рублях
- Обновление общей премии полиса
- Определение статусов платежей
- История изменений (audit log)

#### Уведомления
- Celery задачи для проверки платежей
- Email-уведомления о предстоящих платежах
- Уведомления о просрочках

```bash
pip install -r requirements.txt
python3 manage.py migrate
python3 manage.py loaddata fixtures/initial_data.json
python3 create_superuser.py
python3 manage.py runserver
```

## Версия 1.0.1 (25 ноября 2025)

### 🚀 Docker Deployment

Добавлена полная поддержка Docker и автоматического развертывания:

#### Инфраструктура
- Docker контейнеризация всех компонентов
- Docker Compose для оркестрации
- Nginx reverse proxy с SSL
- PostgreSQL в production
- Redis для Celery
- Автоматические миграции

#### CI/CD
- GitHub Actions workflow для автоматического деплоя
- Деплой на Digital Ocean Droplet
- Автоматические тесты и проверки
- Rollback при ошибках

#### Безопасность
- HTTPS через Let's Encrypt
- Переменные окружения для секретов
- Firewall настройки
- Разделение dev/production окружений

#### Документация
- Полная документация по деплою
- Инструкции по настройке Droplet
- Troubleshooting guide
- Backup/restore процедуры
