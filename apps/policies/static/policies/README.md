## Автозаполнение страхователя

[auto_copy_policyholder.js](js/auto_copy_policyholder.js) при открытии формы
подставляет выбранного лизингополучателя, если страхователь пустой.
При выборе другого непустого клиента обработчик **перезаписывает страхователя,
даже если тот уже заполнен**. После смены клиента проверьте страхователя;
подставленное значение можно изменить вручную.

## Копирование платежа в inline

[copy_payment_inline.js](js/copy_payment_inline.js) добавляет кнопку копирования
строки графика в форме полиса. Новая inline-строка заполняется выбранными полями
исходной, но сохраняется только вместе с формой полиса.

Копируются в том числе даты оплаты/акта и `alliance_paid`: перед сохранением
проверьте их, номер года/взноса, дату, суммы и ставку. Уникальность и ограничения
проверяет модель/форма; копия существующей строки без корректировки может
не пройти валидацию.

В списке платежей отдельное admin action «Копировать выбранные платежи»
открывает добавление с предзаполнением по первому выбранному платежу.
[PaymentScheduleAdmin](../../admin.py) использует `queryset.first()`;
остальные выбранные строки этим действием не копируются.
