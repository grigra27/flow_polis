# Архив документации

Материалы сохранены как история решений и подробные спецификации. Команды,
даты проверки, незакрытые галочки и описание production внутри них относятся
к исходному периоду. Текущие руководства — в [оглавлении](../README.md),
актуальные задачи и решения — только в [BACKLOG.md](../BACKLOG.md).

Статус «архив» прекращает ведение задач в этих файлах, но не отменяет полезные
определения и объяснения решений. При расхождении с руководством сначала
сверяйте текущий исходный код. Удалённые описания ранних версий, старый план
календаря и отменённый проект публичного API доступны в истории Git.
